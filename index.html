Core Foundation

What is a Contour?

A curve joining all the continuous points along a boundary with the same color or intensity.

KEY CONCEPT

The Outline of Shapes

  • • Contour detection connects all border pixels having identical brightness.
  • • It is primarily used for shape analysis, object detection, and size measurement.
  • • For high accuracy, we always apply contours on binary images (black and white)!
Analogy: Think of tracing a marker pen along the outer boundary of a cutout!

What is Thresholding and why do we need it? Thresholding converts a grayscale image into pure Black and White (Binary). Contours require high contrast between the object and the background to trace boundary points without noise.
# Syntax: ret, thresh = cv2.threshold(src, thresh_val, maxval, type)
ret, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
Adjust Cutoff Threshold Value: 127
⚖️ How pixels are decided:
• Pixel intensity > 127 $\rightarrow$ becomes 255 (White)
• Pixel intensity ≤ 127 $\rightarrow$ becomes 0 (Black)

OpenCV Functions

Finding and Drawing Contours

1. FIND CONTOURS cv2.findContours()

What it does: Scans the binary image and extracts the exact list of boundary coordinates surrounding each detected shape.

contours, hierarchy = cv2.findContours(
  thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
)
cv2.RETR_EXTERNAL: Retrieves only outermost boundaries, ignoring interior nested holes.
cv2.CHAIN_APPROX_SIMPLE: Compresses redundant points (e.g. stores only 4 corner vertices for a box).
2. DRAW CONTOURS cv2.drawContours()

What it does: Takes the coordinate list extracted by findContours and paints visible outlines directly onto your image!

cv2.drawContours(img, contours, -1, (0, 255, 0), 3)

Contour Index (-1): Passing -1 commands OpenCV to draw ALL detected contours. Passing 0 draws only the 1st contour.
